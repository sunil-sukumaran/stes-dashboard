# STES — Smart Traffic Enforcement System

A production-grade traffic enforcement command dashboard built with React, Chart.js, and Canvas.

## Deploy to Vercel (3 steps)

### Option A — Vercel CLI (fastest)
```bash
npm i -g vercel
vercel
```
Follow the prompts. Done.

### Option B — Vercel Dashboard (no CLI)
1. Go to https://vercel.com/new
2. Click **"Deploy without a Git repository"** → drag and drop this entire folder
3. Click **Deploy**

### Option C — GitHub → Vercel (recommended for ongoing use)
1. Push this folder to a GitHub repo
2. Go to https://vercel.com/new → Import the repo
3. Leave all settings as default → click **Deploy**

## Features
- Live camera simulation with AI vehicle detection overlay
- Facial recognition — owner vs driver verification
- Driver / vehicle database lookup
- Traffic analytics with Chart.js
- Officer activity & transparency log
- Blockchain audit chain
- System settings

## Tech Stack
- React 18 (CDN, no build step needed)
- Chart.js 4.4
- HTML5 Canvas for camera simulation
- Pure CSS animations
- Zero dependencies — single HTML file
